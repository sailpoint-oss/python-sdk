# SubtypeTargetType

Tier that scopes the subtype. `SOURCE` is unique per source. `CONNECTOR` is unique per connector type and applies to every source of that connector. On create, omitted `targetType` defaults to `SOURCE`. `CONNECTOR_VARIANT` is reserved and is not available for create, update, or delete.

## Enum

* `SOURCE` (value: `'SOURCE'`)

* `CONNECTOR` (value: `'CONNECTOR'`)

* `CONNECTOR_VARIANT` (value: `'CONNECTOR_VARIANT'`)
