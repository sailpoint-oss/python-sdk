# Appliedcontrolstatus

The processing status of a compensating control that has been applied to a policy violation.

* `ACTIVE` (value: `'Active'`)

* `COMPLETED` (value: `'Completed'`)

* `CANCELED` (value: `'Canceled'`)

* `FAILED` (value: `'Failed'`)
